    GitHub-Verbindung
    Zum Speichern wird die Datei data.json direkt im Repository aktualisiert. Dafür brauchst du einen Fine-grained Personal Access Token:
    1. Neuen Token erstellen
    2. „Repository access“ → Only select repositories → dieses Repo
    3. „Permissions“ → Contents → Read and write
    Der Token wird nur in diesem Browser gespeichert (localStorage) und nur an api.github.com gesendet.
    Leer lassen, um nur lokal zu bearbeiten und als JSON zu exportieren.
